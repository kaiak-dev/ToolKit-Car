# What is ToolKit-Car?
This is a hardware project from the StarDance challenge by Hack club. I've always loved to build things, from desks to computers, to everything in between. One thing that you will always need when building something are tools. Tools can often get lost or misplaced, even in a small workspace! I have experienced this one too many times, so I decided to build something to fix that! 
Toolkit car is able to track anyone within a room using a esp32 camera module and an esp32. The esp32 takes the data from the camera, and using a script(I have not yet coded) will send data to 4 motors and allow it to move!

## How to print it?
| CAD files | Do I print it? |
| -------- | ------- |
| Concept.step| No |
| Casing and wheel mount part studio.step | No |
| esp32 casing printing assembly.step | Yes |
| Rail part studio.step| No |
| Rail printing assembly.step| Yes |
| Wheel printing assembly.step| Yes |

| CAD files | What type of filament do I use? |
| -------- | ------- |
| esp32 casing printing assembly.step | **PET-G*** |
| Rail printing assembly.step| **PET-G*** |
| Wheel printing assembly.step| TPU |

_*PET-G can be replaced with either ABS or PLA. **PET-G is reccomended**._

### Printing Steps!
1. Download the .step files listed above.
2. Import the files into a splicer and use **organic/tree supports*** for any overhanging pieces.
3. Glue the build plate using whatever glue is avaliable.
4. Print each of the assemblies seperately, or together.

_*Creality: https://wiki.creality.com/en/software/update-released/Support/support-settings_

_*Bambu:  https://wiki.bambulab.com/en/software/bambu-studio/support_
 
_*Cura: https://ultimaker.com/learn/tree-supports-what-are-they-and-how-do-they-work/_
   
_*Prusa: https://help.prusa3d.com/article/tree-supports_1515_
